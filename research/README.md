# research/

Forschungsdokumente als Markdown mit YAML-Frontmatter – ein Ordner pro Forschungsbereich.
Feldaufbau und Pflichtangaben: siehe `docs/conventions.md`. Regeln: siehe `CLAUDE.md`.

| Ordner | Inhalt |
|---|---|
| `vedas/` | Ṛgveda, Sāmaveda, Yajurveda, Atharvaveda, Śākhās |
| `brahmanas-aranyakas/` | Brāhmaṇas und Āraṇyakas |
| `upanishads/` | Upaniṣaden |
| `sutras/` | Śrauta-, Gṛhya-, Dharma- und Śulba-Sūtras |
| `mahabharata/` | Mahābhārata (Parvans, Figuren, Krieg, Geografie) |
| `bhagavad-gita/` | Bhagavad Gītā |
| `ramayana/` | Rāmāyaṇa und seine Versionen |
| `puranas/` | Purāṇas |
| `cosmology/` | Yugas, Manvantaras, Kalpas, Pralaya, Schöpfung |
| `astronomy/` | Vedische Astronomie, Nakṣatras, Jyotiṣa, Siddhāntas |
| `history/` | Chronologie, Dynastien, Migrationen, historische Geografie |
| `archaeology/` | Indus-Zivilisation und Fundstätten |
| `sanskrit/` | Sprache, Schriften, Grammatik, Terminologie |
| `philosophy/` | Darśanas, Vedānta, Brahman/Ātman, Karma, Mokṣa |
| `other-fields/` | Āyurveda, Mathematik, Musik, Architektur, buddhistische/jainistische Quellen, Vergleiche |
