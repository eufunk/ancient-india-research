# data/

Strukturierte Daten als JSON. Alle Einträge haben eine eindeutige, stabile ID; Verweise erfolgen nur über IDs.
Schemas: siehe `docs/conventions.md`.

| Ordner | Inhalt | ID-Beispiel |
|---|---|---|
| `texts/` | Schriften und Textkorpora | `rigveda` |
| `characters/` | Figuren | `krishna` |
| `dynasties/` | Dynastien und Genealogien | `kuru` |
| `locations/` | Orte, Flüsse, Königreiche, Fundstätten | `loc-kurukshetra` |
| `timeline/` | Ereignisse und Datierungen | `evt-mature-harappan` |
| `references/` | Zentrales Quellenverzeichnis | `src-jamison-brereton-2014` |
| `questions/` | Offene Forschungsfragen | `q-rigveda-dating` |
| `cosmology/` | Rechenmodelle für Visualisierungen (z. B. Yuga-System) | `yuga-system-data` |
